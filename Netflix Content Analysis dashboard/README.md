# Netflix Content Analysis Dashboard

## Project Overview
Analyzed Netflix's content library to identify trends in movies and TV shows, content growth, ratings distribution, and country-level patterns.

## Business Questions
- How has Netflix content changed over the years?
- What is the distribution of Movies vs TV Shows?
- Which countries produce the most Netflix content?
- What are the most common genres on Netflix?
- How has content production changed over time?

## Tools Used
- Python
- Pandas
- NumPy
- Tableau
- Data Visualization
- Data Cleaning

## Dataset Description
This project uses the Netflix Titles dataset containing information about movies and TV shows available on Netflix, including:
- Title
- Type (Movie/TV Show)
- Country
- Release year
- Rating
- Genre
- Duration

## Analysis Steps
1. Loaded and explored the Netflix dataset.
2. Cleaned missing values and duplicate records.
3. Performed exploratory data analysis (EDA).
4. Created visualizations to identify content trends.
5. Built a Tableau dashboard to communicate insights.

## Key Analysis
- Content distribution by type
- Top producing countries
- Release year trends
- Genre analysis
- Ratings distribution

## Key Insights
- Netflix has significantly increased its content library over time.
- Movies represent a larger portion of Netflix's catalog compared to TV Shows.
- The United States is one of the largest content-producing countries.
- Drama and International content are among the most common genres.
